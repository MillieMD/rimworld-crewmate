# Rimworld Crewmate Xenotype

Defines a custom xenotype for the Crewmate race, and adds a faction of entirely crewmates.

Features of crewmates:
- Body -> 1 cuttlebone
    - Head -> Visor -> 2x eyes; skull -> brain
    - Hands -> 2x hands -> 4x fingers each; may need arms; 
    - 2x Legs -> 2x feet -> 4x toes each
    - normal organs

- Bright colours
